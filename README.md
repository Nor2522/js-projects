### 🌟 Maxaa cusub Project 3 (Quiz App)?
Project-kan ugu dambeeyay ee **Islamic Quiz App** wuxuu leeyahay astaamo gaar ah oo aan ku tijaabiyay xirfadayda UI/UX:
* **Shumac Effect:** Progress bar-ka wuxuu leeyahay dab (flame) sii weynaanaya marba marka ka dambaysa.
* **Dual Theme:** Waxaad u kala beddeli kartaa Light Mode iyo Dark Mode.
* **3D Glassmorphism:** Naqshad muraayad u eg oo casri ah.
* **Responsive Design:** Wuxuu si fican ugu shaqaynayaa Mobile-ka iyo Desktop-ka.
